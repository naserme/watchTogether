◈ پراکسی اتاق فعال
پراکسی با Range عبور می‌کند تا seek سریع بماند. صاحب اتاق با VPN خودش پراکسی اتاق را فعال می‌کند — بقیه بدون دیدن کانفیگ استفاده می‌کنند.
میکس 100%
لینک صدای دوبله را بده — با ویدیو سینک می‌شود (تغییر ~30ms). تغییر دوبله برای همه‌ی اتاق اعمال می‌شود تا لینک عوض نشده.
زیرنویس — KMPlayer-style
اول فیلم را لود کن تا زیرنویس‌های داخل خود MKV/MP4 شناسایی شوند — بعد از همین‌جا انتخاب کن. فایل خارجی هم اضافه می‌شود.
تاخیر 0.0s
فیلم را پخش کن تا ترک‌ها شناسایی شوند.
صدا — دوبله / اصلی — ترک داخلی
ترک‌های صدای داخل MKV/MP4 اینجا می‌آیند — مثلا «فارسی» و «English». اگر لیست خالی ماند، مرورگر MKV را کامل پشتیبانی نمی‌کند؛ نسخه MP4 بگیر یا روی Firefox تست کن.
چت/صدا (آینده)
پیام‌های chat از WS عبور می‌کنند — UI فعلاً مخفی تا خلوت بماند.

◈ کانفیگ‌های VPN

لیست ذخیره‌شده (0) — انتخاب دستی یا خودکار
کانفیگ‌ها برای همین اتاق و همین مرورگر (localStorage) ذخیره می‌شن. پراکسی ویدیو از کانفیگ فعال استفاده می‌کنه.
http/socks5 مستقیم با پراکسی کار می‌کنه. vless/vmess/trojan/ss روی این سرور نیاز به Xray TUN داره — اگر نداره فقط پینگ host گرفته می‌شه.
